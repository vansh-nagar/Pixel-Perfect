Release shelf

  • Take Twelve2026

    A browser-based take log. Notes stay attached to the recording time so an editor can find the good ending without listening through the whole session again.

  • Patch Receipt2026

    An equipment checkout log for shared studios. It records the cable, adapter, or microphone actually borrowed, along with who is bringing it back.

  • Mix Envelope2025

    A review page for successive mixes. Listeners can leave comments at a time position and see which version they are hearing before pressing play.

  • Set Interval2025

    A running-order planner that includes changeovers. Moving one performance updates the remaining times without overwriting the breaks the crew needs.

  • Quiet Hours2024

    A booking calendar for rooms with different noise limits. It shows which sessions can run next door to each other and where a buffer is needed.

Soundchecks

  • Finding the clipped peak2026

    A waveform experiment that marks likely clipping for a closer listen. It flags a place to inspect, rather than pretending a picture can judge the recording.

  • One folder, two spellings2025

    A file naming study built from messy session folders. The goal is to find duplicates without renaming or deleting the originals.
